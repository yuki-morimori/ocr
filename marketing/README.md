# 「うつして台帳」マーケティング一式

手書き帳票 汎用エンジンの **現場向けの顔**＝商品名「**うつして台帳**」のための営業アセット集。
（エンジン本体は内部資産として隠し、外には業種特化ツールの顔で出す方針）

## ブランド定義

| 項目 | 内容 |
|------|------|
| 商品名 | **うつして台帳** |
| 一言 | 手書きの紙を、写真を撮るだけで台帳・請求書に。 |
| 誰に | パソコンが苦手・**スマホしかない現場**（産廃 / 運送 / 農業 …） |
| 約束 | **現場のやり方は1ミリも変えない**。増える所作は「撮る」だけ。 |
| 主メッセージ | **「手書きはそのまま。写真を撮ると、台帳になる。」** |
| 裏の強み（言わない） | 文脈読み取り（レイアウト固定しない）／読めない所は推測せず人へ回す段階処理／使うほど賢くなる学習 |
| トーン | 平易・現場語・大きい字。専門用語（OCR/AI/クラウド）は表に出さない |

## メッセージの階層（チラシ・トーク共通）

1. **主**：手書きはそのまま。写真を撮ると、台帳になる。
2. **証拠**：その場で初見の紙を撮って、請求書を30秒でお見せします／御社の紙1枚で無料お試し。
3. **効き目**：月末の転記ゼロ・請求漏れゼロ・スマホだけで完結。
4. **安心**：初期費用0円・月3,980円・1ヶ月無料・設定は全部こちらで代行。

## ファイル

- `01_チラシ_LP原稿.md` … 業種別1枚チラシ／LP原稿（共通＋産廃/運送/農業の差し替え）
- `02_デモ動画台本_15秒.md` … 15秒/30秒のデモ動画 台本・絵コンテ
- `03_競合比較表_料金表.md` … 競合比較表＋料金プラン
- `チラシ.html` … 印刷・送付用の1枚チラシ（A4・そのまま配れる）

## 使い分け（営業の動線）

```
認知（団体・紹介・LP・15秒動画）
  → 興味（その場デモ / 紙1枚お試し）
    → 試用（1ヶ月無料・設定代行）
      → 契約（月3,980円〜）
        → 継続（学習で精度UP＝乗り換え損 ＋ 法令オプションで必須化）
```
